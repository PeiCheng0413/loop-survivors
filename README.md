# 迴圈生存者 loop-survivors

教學用 2D 網頁彈幕遊戲。玩家的攻擊完全由**積木程式**決定——不能瞄準，
打得贏就代表程式寫得好。設計目的是讓學生自己撞出「迴圈」的價值。

**線上試玩**：https://peicheng0413.github.io/loop-survivors/

## 玩法

| 按鍵 | 功能 |
|---|---|
| `WASD` / 方向鍵 | 移動（**不能瞄準**，攻擊全交給腳本） |
| `1` ~ `4` | 切換攻擊腳本 |
| 空白 | 暫停 |
| `R` | 重來 |

左上角面板是目前的攻擊腳本，黃色高亮會跟著執行位置跑——可以直接看見迴圈在繞圈。

按 `1` 和按 `4` 比較看看：同樣八個方向，一個是單層迴圈，一個是巢狀迴圈。

```
按 1 散彈手            按 4 巢狀測試
重複 8 次:             重複 8 次:
  方向旋轉 45 度         方向旋轉 45 度
  發射子彈               重複 3 次:
                           發射子彈
                           方向旋轉 6 度

3 格 → 每輪 8 發       5 格 → 每輪 24 發
```

多兩格積木，火力三倍——這就是這個遊戲想教的事。

## 目前進度

**M0**：遊戲骨架 + 積木直譯器（腳本仍是手寫 JSON，尚未接上 Blockly 編輯器）。
平衡尚未調整，火力偏弱是預期內的。

完整的設計決策與理由記在 [`docs/DECISIONS.md`](docs/DECISIONS.md)。

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 產出純靜態檔到 dist/
```

vanilla TypeScript + Vite，零執行期相依、零圖檔、無後端。
